# nvim config
[![ci](https://github.com/yikesboy/nvim/actions/workflows/ci.yml/badge.svg)](https://github.com/yikesboy/nvim/actions/workflows/ci.yml)

my personal lightweight nvim config, built declaratively with [nixvim](https://github.com/nix-community/nixvim)

## helpful commands
### validation
`nix flake check`
### build
`nix build .#neovim`
### updating
`nix flake update`
### formatting
`nix fmt`
### neovim health inspect
`:checkhealth`
